# Pedro Yarin — Landing page

Página em HTML, CSS e JavaScript com imagens e fonte locais. Não exige instalação de pacotes nem compilação.

## Versão atual

A capa continua horizontal e panorâmica. O rosto visível agora vem do retrato nítido de referência, na proporção natural 1151:1367, sem compressão na largura ou na altura e sem filtro de desfoque. O fundo horizontal é uma camada separada; as bordas do retrato se integram a ele de forma suave. A escala foi conferida no computador e em celulares de 390 e 320 pixels. As cinco imagens dos segmentos foram criadas por IA, com alta definição e iluminação azul suave. Foram mantidos o neon, os carrosséis contínuos e os contadores de 20 segundos.

## GitHub e Vercel

1. Extraia este ZIP no computador.
2. Crie um repositório no GitHub e envie o conteúdo extraído. Mantenha `index.html`, `vercel.json` e a pasta `assets` na raiz do repositório.
3. Na Vercel, escolha **Add New → Project**, importe esse repositório e clique em **Deploy**.
4. O `vercel.json` já configura o site. Se a Vercel pedir os campos: **Framework Preset: Other**, **Root Directory: ./**, **Build Command: vazio**, **Output Directory: .**. Não há comando de instalação.

Envie ao GitHub os arquivos extraídos, em vez do ZIP fechado. Nenhuma chave ou variável de ambiente é necessária.

## Visualizar e editar

Abra `index.html` depois de extrair o ZIP. Preserve a pasta `assets` ao lado do HTML. Os textos, estilos, animações e links de WhatsApp ficam no HTML. As fotografias, os logotipos e a fonte ficam em `assets`.

A licença da fonte está em `assets/fonts/LICENSE.txt`. A origem e as dimensões das imagens estão em `CREDITOS-IMAGENS.md`. Os prompts usados com o gerador integrado e os caminhos de cada imagem estão em `PROMPTS-IMAGENS.md`.

Documentação: https://vercel.com/docs/builds
